WHY THIS PROJECT

將硬體底層與雲端，

◌

感測與底層驅動

DHT11 單線協定、超音波微秒時序、LDR 類比 ADC 轉換與 PIR 中斷解碼。

⌁

連線與網路通訊

Wi-Fi 狀態機管理、MQTT 遙測上報與反向控制、ThingSpeak 及 LINE 告警。

匯流排與多端顯示

I2C OLED 動態渲染、SPI ILI9225 彩色 TFT UI，與低功耗 E-Paper 狀態儀表板。
